# Check sets

`chat_check.json`: 48 chat lines, each naming an everyday thing about someone in passing without asking
anything (R-083). Written on 2026-11-05 by a fresh Sonnet agent that read only its brief and ran only a
checker that names the writer's own lines; its transcript was checked. Never used in training. Used by
`run_recall_eval.py --chat-check` as the `statement` lines of a development check.
